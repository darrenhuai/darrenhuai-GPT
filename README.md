# GPT

A small GPT-style language model implemented in Python with PyTorch and NumPy.

The project was trained on a batch of Petrarch's Italian sonnets and used to generate fluent Petrarchan-style sonnet text. It is intended as a learning project for understanding transformer language models, tokenization, training loops, and text generation.

## Project goals

- Build a GPT-style model from core deep learning components.
- Train on a focused poetry dataset instead of a generic corpus.
- Compare PyTorch and NumPy implementations where useful.
- Provide a notebook or Colab demo for reproducible experiments.
- Generate readable sonnet-style text from learned patterns.

## Current status

This is an educational NLP project. It is not intended to be a production chatbot or general-purpose text generation system.
