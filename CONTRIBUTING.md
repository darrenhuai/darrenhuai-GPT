# Contributing

This repository is primarily an educational NLP project, but small improvements are welcome.

## Good contribution areas

- Clearer setup instructions
- Reproducible training commands
- Sample generated outputs
- Cleaner notebook explanations
- Experiment tracking notes
- Small tests for utility functions

## Development expectations

- Keep commits focused and descriptive.
- Do not commit large model checkpoints unless they are intentionally tracked.
- Do not commit local notebook outputs if they make diffs noisy.
- Include enough context for another person to reproduce your experiment.

## Suggested pull request checklist

- [ ] Explain what changed.
- [ ] Note whether training behavior changed.
- [ ] Include sample output if generation changed.
- [ ] Mention any new dependencies.
